A place to pick up again

Keep the work you return to within reach.

Keep the useful things close

A folder for the project. A file for the next thought. Favorites keeps both beside the document, arranged in the groups you choose.

One quiet place to return to the work.

A quieter way back

Try Add, Manage groups, or searching for “Projects”. Sidebar editing pages stage changes until Save. The panel here is the same component that the plugin loads in Typora.

The surrounding editor and Recent data are synthetic fixtures. Navigation, reveal and the Recent list are simulated; this page has no filesystem access. Favorites reads Typora's real Recent list only inside Typora, on Windows and macOS.
